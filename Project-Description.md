# Project overview
Create a more accurate and COTS-like flight computer for the 2027 [IREC](https://www.soundingrocket.org/what-is-irec.html) competition. Large goals would include adding GPS tracking, testing the final flight status of the flight computer (post-flight data/general testing of the instrument), increased accuracy in measurement readings, as well as developing testing for pyrotechnics/parachutes.
